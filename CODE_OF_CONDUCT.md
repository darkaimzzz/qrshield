# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short, we expect everyone participating in QRShield's issues, pull requests and discussions to:

- be respectful and welcoming, regardless of background or experience level;
- give and accept constructive feedback gracefully;
- focus on what is best for the project and its users;
- not harass, insult or demean others, publicly or privately;
- not publish others' private information without explicit permission.

## Enforcement

Report unacceptable behavior to the maintainer through a private GitHub channel (for example a private security advisory, or a direct message to [@darkaimzzz](https://github.com/darkaimzzz)). Reports are reviewed promptly and kept confidential. The maintainer may remove, edit or reject contributions, or temporarily or permanently ban contributors, for behavior they deem inappropriate, following the enforcement guidelines of the Contributor Covenant.
